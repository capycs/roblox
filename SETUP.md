# Eggnappers: what's here and how to get it into Studio

Everything is generated by code in `tools/art` (three.js, rendered headless). Re-run any part with
`cd tools/art && npm i` then `npm run build` (creatures), `npm run props`, `npm run textures`,
`npm run fx`, `npm run icons`, `npm run sky`, then `npm run prop-anim` and `npm run asset-ids`.

## 1. Import the 3D models (Avatar tab > Import 3D, scale unit **Stud**, rotation 0)

| What | Files | Put the models in |
|---|---|---|
| 6 creatures | `assets/creatures/<Name>/<Name>.glb` | `ServerStorage/Creatures` (name = species) |
| Skyship | `assets/props/Skyship/Skyship/Skyship.glb` | `ServerStorage/Props/Skyship` |
| Props (95 more) | `assets/props/<Category>/<Name>/<Name>.glb` | anywhere in the map; keep the model name |
| Butterfly, Bird | `assets/props/Atmosphere/...` | `ReplicatedStorage/Props/Ambient` |

Run `require(game.ReplicatedStorage.Shared.Props.PropSetup).prepareAll(workspace)` once in the
command bar after placing props (sets Neon/Glass and tags moving parts), or call `prepare` per model.

## 2. Upload the images and paste their IDs into `src/shared/AssetIds.luau`

Asset Manager > Bulk Import, then copy each ID:
- `assets/ui/icons/*.png` (54 UI icons)
- `assets/fx/textures/*.png` (41 particle textures)
- `assets/textures/<Name>/{color,normal,roughness}.png` (14 terrain materials)
- `assets/sky/{Day,Dusk}/{Bk,Dn,Ft,Lf,Rt,Up}.png` (skyboxes)
- `assets/creatures/<Name>/previews/hero.png` (portraits for the Index and hatch reveal)

Anything still at `rbxassetid://0` is skipped (icons show a coloured placeholder). Re-running
`npm run asset-ids` keeps IDs you already filled in.

## 3. Place a few marker parts

- `Workspace/SkyshipDock` (Part): where the skyship docks in Haven.
- `Workspace/WildsDrop` (Part): where passengers land (local mode; set `WildsPlaceId` in `SkyshipConfig` for a real place).
- `Workspace/Zones/<Preset>` (invisible Parts named `Haven`, `Verdant`, `Ember`, `Frost`, `Storm`, `Tide`, `Shadow`): lighting, sky and ambient particles switch when the camera enters one.
- Tag Parts `ButterflySpot` (flower beds) and `BirdCircle` (above Haven) for wildlife.
- Tag every sky island model `SkyIsland`: anime wind swirls curl over them at random.

## 4. Sync code (Rojo, `default.project.json`) and press Play

- **Creatures:** walk, run, attack and roar in a row in front of the spawn (CreatureDemo).
- **Props:** every moving part animates on the client: propellers, sails, swaying trees and grass, waving flags, swinging lanterns, hovering crystals, flickering flames.
- **UI:** HUD, shop, Index, incubators, hatch reveal, expedition HUD and the skyship timer, all running on demo data in `src/client/UI/State.luau`.
- **Outlines:** the nearest ~28 creatures/props/players get a cartoon outline (Highlight pool, `AtmosphereConfig.Outlines`). Tag anything else `Outline` to include it.
- **Wind:** wind swirls over `SkyIsland`s plus streaks, leaves and motes that drift with `GlobalWind`.
- **Effects:** `Effects.burst("HatchBurst", cframe, { color = ... })` on the client, or `FxService.play(...)` from the server.

Product and game-pass IDs go in `src/shared/Shop/ShopCatalog.luau`.

Not yet tested inside Roblox Studio: the Luau compiles, and the creature animation maths matches the previews exactly.
