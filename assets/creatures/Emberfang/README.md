# Emberfang

Cartoony fire wolf, the hero creature. `Emberfang.glb` is generated by `tools/emberfang` (run `npm i && npm run build` there). Previews are in `previews/`.

- 4 skinned meshes sharing one 26-bone skeleton: `Body` (palette texture), `Eyes`, `Flame`, `FlameCore` (set to Neon by `CreatureSetup`).
- About 20.5k triangles total; Body is under 15k (Roblox limit is 20k per mesh).
- Faces -Z (Roblox forward), units are studs: about 6 studs long, 6 tall to the flame tip.
- Animation is code-driven on the bones (`src/shared/Creatures`): Idle, Walk, Run, Attack, Roar, plus springs on head, ears and tail. The same clips are also baked into the GLB.

## Import into Studio

1. Avatar tab > **Import 3D** (or File > Import 3D), pick `Emberfang.glb`.
2. In the import options set the scale unit to **Stud**. Keep rig/skinning on. Leave rotation at 0.
3. Import. Rename the model `Emberfang` and move it to `ServerStorage/Creatures/Emberfang` (create the `Creatures` folder).
4. Sync the code (Rojo, `default.project.json`) and press Play. The demo script spawns Emberfang 24 studs in front of the spawn and runs every animation on a loop.

If it walks backwards, set `yawOffset = 180` in `CreatureConfig`. If legs bend sideways, the importer rotated the rig: re-import with rotation 0.
