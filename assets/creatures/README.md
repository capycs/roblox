# Creatures

16 cartoony creatures across 7 elements, Common to Mythic. Every `.glb` is generated by `tools/art` (`npm i && npm run build`, or `npm run build -- voltgriff` for one). Each creature's descriptions, abilities and mutations are in `docs/CREATURES.md`.

Each creature folder contains:
- `<Name>.glb`: the rigged model with baked clips.
- `previews/`: renders, including `hero.png` (the portrait) and `mut_<Mutation>.png`.
- `mutations/<Mutation>.png`: Body textures for the Shiny, Golden, Crystal, Void and Rainbow mutations.

| Rarity | Creatures |
|---|---|
| Common | Bramblepup (Nature), Shellsnap (Water) |
| Uncommon | Sparkit (Storm), Mossback (Nature) |
| Rare | Tidefin (Water), Blazehorn (Fire), Frostfawn (Ice) |
| Epic | Emberfang (Fire), Frostusk (Ice), Umbrapaw (Shadow) |
| Legendary | Voltgriff (Storm), Nyxwing (Shadow), Solarion (Fire), Glaciarch (Ice), Sylvanthorn (Nature) |
| Mythic | Aetherion (Prism) |

Every mesh is under Roblox's 20k-per-mesh limit; the triangle counts are in `docs/CREATURES.md`.

- **Meshes:** each model is a few skinned meshes sharing one skeleton.
  - `Body` uses the palette texture.
  - Glow meshes (`Eyes`, `Glow`, `GlowCore`, `Flame`/`FlameCore`, and on Aetherion `Prism` and `Orb*`) are turned Neon by `CreatureSetup`.
- **Bones:** every creature uses the same 26 base bones, so one animation system drives them all (`src/shared/Creatures/Poses/Quadruped.luau`). Each species has a style in `CreatureConfig`.
- **Spinner bones:** winged creatures add wing bones. Legendaries and the mythic add extra spinner bones (halos, orbiting orbs, hovering crowns, rune rings), driven by `spinners` in `CreatureConfig`.
- **Animations:** Idle, Walk, Run, Attack and Roar, plus springs on the head, ears, tail and wings, and a lean into turns. The same clips are baked into each GLB, spinners included.
- **Orientation and units:** models face -Z (Roblox forward); units are studs.

## Import into Studio

1. Avatar tab > **Import 3D**, then pick a `.glb`. Set the scale unit to **Stud**, keep rig/skinning on, and leave rotation at 0.
2. Name the model exactly after the species (`Voltgriff`, ...) and put it in `ServerStorage/Creatures`.
3. Repeat for each creature, sync the code (Rojo, `default.project.json`) and press Play.
   - The demo spawns every creature in that folder in a row in front of the spawn.
   - It loops walk, roar, run and attack.

If one walks backwards, set its `yawOffset = 180` in `CreatureConfig`. If its legs bend sideways, the importer rotated the rig: re-import with rotation 0.
