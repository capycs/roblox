# Creatures

Six cartoony creatures, one per element. Every `.glb` is generated by `tools/creatures` (`npm i && npm run build`, or `npm run build -- voltgriff` for one). Previews are in each `previews/` folder.

| Creature | Element | Body | Tris (Body / total) | Bones |
|---|---|---|---|---|
| Emberfang | Fire | Fire wolf, flaming tail | 14,796 / 20,474 | 26 |
| Voltgriff | Storm | Griffin, feathered wings, lightning tail | 19,732 / 21,636 | 32 |
| Frostusk | Ice | Heavy tusked beast, ice crystals on its back | 15,884 / 17,340 | 26 |
| Nyxwing | Shadow | Drake, membrane wings, shadow-flame tail | 15,868 / 18,150 | 32 |
| Tidefin | Water | Otter-axolotl, gill fronds, fluke tail | 11,920 / 17,292 | 26 |
| Mossback | Nature | Boar with mossy stone plates and spore flowers | 12,876 / 15,680 | 26 |

Each mesh is under Roblox's 20k-per-mesh limit.

- Each model is a few skinned meshes sharing one skeleton: `Body` (palette texture) plus glow meshes (`Eyes`, `Glow`, `GlowCore`; Emberfang uses `Flame`/`FlameCore`) that `CreatureSetup` turns Neon.
- All creatures share the same bone names, so one animation system drives them all (`src/shared/Creatures/Poses/Quadruped.luau`). Each species has a style in `CreatureConfig` (speed, weight, tail swing, wings, bite or charge attack).
- Animations: Idle, Walk, Run, Attack, Roar, plus springs on head/ears/tail/wings and lean into turns. The same clips are baked into each GLB.
- Faces -Z (Roblox forward), units are studs.

## Import into Studio

1. Avatar tab > **Import 3D**, pick a `.glb`. Set the scale unit to **Stud**, keep rig/skinning on, rotation 0.
2. Name the model exactly after the species (`Voltgriff`, ...) and put it in `ServerStorage/Creatures`.
3. Repeat for each creature, sync the code (Rojo, `default.project.json`) and press Play. The demo spawns every creature in that folder in a row in front of the spawn and loops walk, roar, run and attack.

If one walks backwards, set its `yawOffset = 180` in `CreatureConfig`. If legs bend sideways, the importer rotated the rig: re-import with rotation 0.
